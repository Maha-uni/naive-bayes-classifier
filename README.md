# Naive Bayes Classifier

## Description

This project implements a Naive Bayes classification algorithm from scratch using Python.

## Dataset

The Iris dataset from scikit-learn is used to classify flowers into three species:

- Setosa
- Versicolor
- Virginica

## How It Works

1. Loads the Iris dataset.
2. Splits the data into training and testing sets.
3. Trains the Naive Bayes classifier.
4. Predicts the class of a flower based on its measurements.
5. Compares the predicted class with the actual class.

## Requirements

- Python
- NumPy
- Scikit-learn

## How to Run

Install the required libraries:

```bash
pip install numpy scikit-learn
```

Run the program:

```bash
python naive_bayes.py
```

## Output

The program displays the flower's measurements, predicted class, and actual class.
